# Система новостей BilimCert

Эта папка содержит новости в формате Markdown, которые автоматически отображаются на сайте.

## Структура файла новости

Каждый файл новости должен содержать frontmatter (метаданные) в начале файла:

```markdown
---
id: 1
title: "Заголовок новости"
excerpt: "Краткое описание новости для превью"
image: "/images/news/image.jpg"
category:
  id: 1
  name: "Категория"
  slug: "category-slug"
  color: "bg-blue-500"
tags:
  - "тег1"
  - "тег2"
publishedAt: "2024-01-15T10:00:00Z"
featured: true
viewsCount: 1250
author: "Автор"
---

# Заголовок новости

Содержание новости в формате Markdown...
```

## Обязательные поля

- `id` - уникальный идентификатор новости
- `title` - заголовок новости
- `excerpt` - краткое описание (отображается в списке новостей)
- `category` - категория новости с полями:
  - `id` - ID категории
  - `name` - название категории
  - `slug` - URL-slug категории
  - `color` - цвет категории (Tailwind CSS класс)
- `publishedAt` - дата публикации в формате ISO 8601
- `featured` - является ли новость рекомендуемой (true/false)
- `viewsCount` - количество просмотров

## Опциональные поля

- `image` - путь к изображению новости
- `tags` - массив тегов
- `author` - автор новости

## Категории

Доступные категории:

- **Аккредитация** (`accreditation`) - `bg-blue-500`
- **Тану** (`recognition`) - `bg-green-500`
- **Болон процесі** (`bologna`) - `bg-purple-500`
- **Цифрландыру** (`digitalization`) - `bg-indigo-500`

## Создание новой новости

1. Создайте новый `.md` файл в папке `content/news/`
2. Имя файла должно быть в формате `slug-новости.md`
3. Добавьте frontmatter с метаданными
4. Напишите содержание в формате Markdown
5. Сохраните файл

## Форматирование Markdown

Поддерживаются все стандартные элементы Markdown:

### Заголовки
```markdown
# H1
## H2
### H3
```

### Списки
```markdown
- Элемент списка
- Другой элемент

1. Нумерованный список
2. Второй элемент
```

### Ссылки и изображения
```markdown
[Текст ссылки](https://example.com)
![Alt текст](путь/к/изображению.jpg)
```

### Таблицы
```markdown
| Заголовок 1 | Заголовок 2 |
|-------------|-------------|
| Ячейка 1    | Ячейка 2    |
```

### Код
```markdown
`inline код`

```javascript
// Блок кода
console.log('Hello World');
```
```

## Автоматическое обновление

После добавления нового файла новости:
1. Новость автоматически появится в списке на `/news`
2. Будет доступна по адресу `/news/slug-новости`
3. Категории обновятся автоматически
4. Поиск будет работать по заголовку, описанию и тегам

## Рекомендации

1. Используйте осмысленные slug'и для файлов
2. Добавляйте качественные изображения
3. Пишите информативные excerpt'ы
4. Используйте подходящие теги
5. Проверяйте правильность дат
6. Следите за уникальностью ID
